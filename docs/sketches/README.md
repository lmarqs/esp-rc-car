# Sketches

- [Blink](blink.md): toggles the LED on GPIO 2 to prove a build, an upload and the board work.
- [Omnidirectional](omnidirectional.md): drives a four-wheel robot from a gamepad or an I2C master, and stops when
  its input goes quiet.
- [Servo](servo.md): sweeps a hobby servo on GPIO 13 to check the servo and its wiring.
